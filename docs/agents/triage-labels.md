# Triage labels

Canonical roles map directly to these GitHub labels:

- needs-triage: maintainer evaluation needed.
- needs-info: waiting for more information.
- ready-for-agent: fully specified and ready for agent implementation.
- ready-for-human: requires human implementation.
- wontfix: will not be actioned.

Use these mappings when engineering skills refer to triage roles.
Preserve existing unrelated labels and historical maintenance labels.
Do not bulk relabel existing issues during setup.
